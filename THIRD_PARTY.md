# Third-party license and attribution notes

The core is MIT. JMH/JCStress, Lincheck, JUnit and jqwik are test dependencies.
Logback is used by test tools; the core runtime binder is SLF4J Simple.
The standalone atmosphere agent has additional runtime dependencies (Jetty EE10, Atmosphere, JLine,
the ACP SDK); its folder carries its own `LICENSE` and `THIRD_PARTY.md`.
The natives jars and the Android AARs contain compiled third-party code: llama.cpp/ggml and what it
vendors, BoringSSL, the GPU vendors' header libraries and the npm packages of the embedded WebUI.
Their license texts travel with them (see below; `llama/legal/natives/NOTICE.md` is the index).

## Review evidence

See [the dependency license review](https://github.com/bernardladenthin/actions/blob/main/docs/dependency-license-review.md) of bernardladenthin/actions
for exact-version evidence and remaining decisions. This inventory is not an approval of all
licenses found by a scanner. Test-tool redistribution requires a separate review.

For unchanged Maven components, source is available from
`https://repo.maven.apache.org/maven2/<groupId with slashes>/<artifactId>/<version>/`
as `<artifactId>-<version>-sources.jar`; POMs and upstream source repositories provide provenance.
Preserve copyright, license and NOTICE files when redistributing dependencies.

java-llama.cpp ships no fat JAR, and Maven resolves every dependency as an artifact of its own,
with its own legal files. Each JAR built from a module's classes (and the CPU AAR, whose
`classes.jar` is the core's) carries this file and `LICENSE` under
`META-INF/third-party/net.ladenthin/<artifactId>/`. Every natives JAR carries
`llama/legal/natives/` under `META-INF/third-party/natives/` (the AARs inside their `classes.jar`,
under `META-INF/third-party/<artifactId>/natives/`): java-llama.cpp's own `LICENSE`, the texts of
every component compiled into a natives directory, each from its upstream byte for byte (its
`SOURCE.txt` says where), and the npm package texts of the WebUI (`webui-npm/`, generated by
`.github/webui-licenses.py` from the pinned `tools/ui/package-lock.json`, which `build-webui`
checks). A jar carries the texts of every kind of natives directory; `NOTICE.md` says which
component is in which.
The license collector of bernardladenthin/actions (`actionlib.java.thirdpartylicenses`), which puts
dependency legal files into the runnable fat JARs of BitcoinAddressFinder and srcmorph, does not run here.
This source-location statement does not clear unknown proprietary or historical Git findings.
